Current Problem

2. 任务卡

4. 任务前小课

问题：任务列表（导航）在顶部占据了大量垂直空间，真正需要阅读的任务内容被挤到下方。

优化方案

两种思路，都解决"先读任务，再编码"的优先级问题

A

精简任务导航 + 提升任务卡

任务列表折叠为顶部横向条，任务卡内容优先展示

  • 任务列表从纵向卡片 → 横向紧凑标签条（只显示 Day + 状态点）
  • 释放的垂直空间给任务卡、验收标准、小课
  • 任务卡区域增加视觉权重：更大的标题、更清晰的层级
  • 左侧面板改名为 "任务详情"，而不是 "任务面板"
B

左栏只保留任务内容，导航放到顶部

将导航与内容彻底分离

  • TopBar 下方增加横向任务进度条：Day 0 → Day 1 → Day 2 ...
  • 左侧面板完全留给任务内容：背景 → 目标 → 验收标准 → 小课 → 知识点
  • 左侧面板标题改为 "当前任务"，阅读流更自然
  • 进度条显示完成状态（绿/灰），点击可跳转
C

A + B 结合（推荐）

横向进度条 + 精简左侧面板内容

  • TopBar 下方：横向 Day 进度条（紧凑，不占太多高度）
  • 左侧面板：任务卡详情（背景、目标、验收标准、小课、知识点）
  • 任务列表完全从左栏移除，不再重复占用空间
  • 阅读顺序：读任务详情 → 编码 → 看反馈
