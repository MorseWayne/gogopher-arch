# 从“语法认识”走到“语义能用”

这一步不追求背完整语法，而是建立写数据处理函数时最常用的判断：一个值的类型是什么、零值能否直接使用、字符串长度到底按什么单位计算、每个分支更新哪些状态。

## 先建立四个支点

1. `var result Summary` 已经是合法值。数字字段从 0 开始，slice 从 nil 开始且可以 `append`。
2. `Label` 是命名类型。把清洗后的 `string` 放进去时要显式写 `Label(name)`，让领域含义在类型上可见。
3. Go 字符串保存 UTF-8 字节。`len(s)` 是字节数，任务契约要求的 Unicode code point 数应使用 `utf8.RuneCountInString`。
4. 循环中的拒绝分支处理完就 `continue`，让接受路径保持单一，避免同一条输入被重复统计。

## 为什么中文样例很重要

只用 ASCII 测试时，字节数和 rune 数通常相同，错误实现也会通过。`你好` 有 2 个 rune，却占 6 个 UTF-8 字节；它能直接暴露错误的长度心智模型。

官方语言规范是语义基准，可重点查阅字符串、rune、转换、零值和 `for range`：[The Go Programming Language Specification](https://go.dev/ref/spec)。规范适合确认边界，不要求从头线性阅读。
