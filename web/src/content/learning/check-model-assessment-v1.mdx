# 独立实现一个有不变量的领域对象

这次评估只给出 API 外形和行为契约。你要完成一个始终保持合法状态的 `Target`，而不是让调用方直接修改字段后再祈祷它们彼此一致。

## 评估边界

构造阶段拒绝空白名称和无效上限，并保存规范化名称。事件方法只维护连续失败事实；`State` 和 `Label` 从事实派生。成功事件必须让已经 open 的目标恢复 ready。

隐藏检查会覆盖多个非法构造输入、超过上限后的状态、恢复路径，以及失败操作是否留下合法对象。公开测试通过不代表已经覆盖这些不变量。

## 独立完成规则

先画出状态转换，再实现；不要先堆条件等待测试逐条纠错。若使用提示或 AI，仍可以获得反馈，但验证状态需要一次未使用帮助的独立提交。完成小结说明哪些字段是事实、哪些值是派生结果。
