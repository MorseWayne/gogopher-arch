# 用事件批次证明集合语义

这次评估把 slice 快照和 map 覆盖规则放在一起。你需要独立实现两个边界明确、可以被其他代码安全使用的函数。

## 验收关注点

- 非法窗口统一返回 nil，合法窗口返回独立存储。
- 修改输入不会污染快照，修改快照也不会回写输入。
- 索引始终可写，空输入返回非 nil 空 map。
- 同一个 key 多次出现时，以输入中最后一项为准。

公开测试验证基本值，提交检查会双向修改 slice，并检查空 map 与重复 key。不要通过比较单个样例来推断实现，先用一句话写清每个函数的所有权和覆盖契约。

如果需要确认语言机制，只按问题查阅 [Go Slices: usage and internals](https://go.dev/blog/slices-intro) 和[语言规范中的 map、slice 章节](https://go.dev/ref/spec)。最终验证仍要求不使用帮助独立通过。
