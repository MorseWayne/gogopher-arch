# 从事件切片迁移到字节帧

这次没有 `Event` struct，输入换成协议字节帧，但核心问题没有变：返回的 payload 是临时视图还是可长期持有的独立值？统计 map 是只读零值还是调用方可以继续写入的集合？

## 独立复验清单

1. 先处理 header 边界，再决定合法空 payload 的返回方式。
2. 复制 payload，分别从 frame 和 payload 两侧修改验证不共享。
3. 初始化 frequency map，让空输入也满足可写契约。
4. 不依赖字符编码；这里统计的是原始 byte，而不是 rune。

本次不提供提示和参考资料。请根据 README、类型和测试重新建立所有权模型，提交后由隐藏变式检查迁移能力。
