# 让类型维护状态，而不是让调用方拼规则

从 C++ 转到 Go 时，很容易把 struct 写成一组字段加 getter/setter，或先寻找继承层级。这次练习换一个起点：哪些值一旦出现就不合法，哪些操作会改变状态，哪些状态可以从事实派生。

## 三类职责

- `NewCheck` 建立不变量：名称非空，失败上限有效。
- `Record` 表达事件：成功清零，失败累计。
- `Health` 从当前事实派生状态，不额外维护一个可能不同步的布尔字段。

值接收者适合只读取状态，指针接收者用于修改同一个 `Check`。这里不需要基类，也不需要为每个字段提供访问器；方法名直接表达领域行为。

[Effective Go](https://go.dev/doc/effective_go) 可用于查看 methods、pointers vs values、embedding 等惯用写法。它是长期维护的经典文档，但不覆盖全部现代 module、testing 和 generics 生态，因此这里只按明确阅读目标使用。
