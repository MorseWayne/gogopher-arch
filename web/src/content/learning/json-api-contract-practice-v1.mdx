## 先把 HTTP 语法变成稳定契约

这一节不再练路由和 server 生命周期，而是练客户端真正依赖的边界：字段名、状态码、JSON 结构和错误 code。

使用 `json.Decoder.DisallowUnknownFields` 拒绝拼错字段，并继续解码一次确认 body 中只有一个 JSON 值。校验错误属于客户端输入问题；领域冲突和内部失败则必须通过 `errors.Is` 分别映射，不能直接把 Go error 文本写回响应。

### 完成标准

- 成功响应和所有错误响应都是 JSON。
- 未知字段、尾随 JSON 和非法业务字段都被拒绝。
- 错误 `code` 稳定，`message` 面向调用者，内部实现细节不泄漏。
