# 读懂 Go 工具链反馈

这节课不要求你先写新功能，而是建立一条可靠的本地反馈回路：知道 Build、Test、Vet 各自在检查什么，也知道失败时应该先看哪里。

## 你将完成

1. 运行 **Build**，确认当前 module 能够编译。
2. 运行 **Test**，确认公开行为测试通过。
3. 运行 **Vet**，检查常见的静态可疑写法。
4. 用自己的话写下三者的区别，以及遇到失败时你的第一步排查动作。
5. 提交本次学习结果。

## 完成标准

- 工作区已保存；
- Build、Test、Vet 都至少运行一次；
- 完成小结不少于 20 个字；
- 最终提交能够完成工具链检查。

不要修改 `go.mod`。如果某一步失败，优先阅读输出中的第一条有效错误，而不是从最后一行开始猜。
